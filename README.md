# BAD READING CLUB

Книжный клуб на React, Vite, TypeScript и Supabase. Публичная часть доступна без аккаунта; организаторы редактируют данные через `/admin` (в адресе GitHub Pages используется `#/admin`). Оценки заносятся вручную после голосования в Telegram.

## Локальный запуск

Нужен Node.js 22. Скопируйте `.env.example` в `.env`, укажите URL проекта и **publishable/anon key** Supabase, затем выполните:

```sh
npm install
npm run dev
npm run typecheck
npm run build
```

Не используйте `service_role` или секретные ключи в браузере и не добавляйте `.env` в Git. Без настроенных ключей автоматически включается деморежим: примерные книги, встреча, оценка и отзыв помечены в интерфейсе как вымышленные, а изменения сохраняются в localStorage этого браузера. Для входа в демоадминку подойдут любые непустые email и пароль. Кнопка в верхней плашке возвращает исходные демоданные. При наличии обоих параметров Supabase используется настоящая база; `VITE_DEMO_MODE=true` принудительно включает деморежим. Демо не обеспечивает авторизацию или защиту данных и предназначено только для локального просмотра.

## Supabase

1. Создайте проект Supabase. В SQL Editor выполните `supabase/migration.sql` целиком один раз. Миграция создаёт таблицы, RLS, приватный bucket `club-media`, политики Storage и единственную начальную книгу «К востоку от Эдема». Даты, адреса, отзывы и оценки не выдуманы.
2. В Authentication отключите публичную регистрацию (Allow new users to sign up), затем создайте пользователя администратора через панель Authentication → Users → Add user, задав email и пароль. Подтвердите email при создании. В SQL Editor вручную назначьте администратора, подставив UUID из списка пользователей:

```sql
insert into public.admin_users (user_id) values ('UUID-ПОЛЬЗОВАТЕЛЯ');
```

Первого администратора можно назначить только через доверенный доступ к проекту, обычный пользователь не может назначить себя. Повторите для других организаторов. Удаление строки отзывает доступ. Не делайте эти операции из клиентского приложения.
3. Скопируйте Project URL и publishable (или legacy anon) key в `.env`. Перезапустите Vite. Войдите в `#/admin` указанными email и паролем. Добавьте встречу, обложку и другие сведения; отметьте записи как опубликованные. Для фотографий сначала сохраните встречу, затем откройте её на редактирование.
4. При использовании ограничений доступа к API проверьте, что клиентам разрешены Data API и Storage. Bucket приватный: публичный доступ к файлу разрешается только при ссылке на опубликованную книгу или опубликованную встречу опубликованной книги. На странице создаются временные ссылки; уже выданная ссылка работает до окончания срока (один час), даже если запись скрыта. Файлы автоматически уменьшаются в браузере и сохраняются в WebP. При удалении записи приложение удаляет связанные файлы; если сеть прервётся между удалением записи и файла, проверьте bucket на оставшиеся файлы вручную.

## GitHub Pages

В настройках репозитория в Settings → Pages выберите Source: GitHub Actions. Добавьте repository variables `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` и `VITE_BASE_PATH`. Для project pages значение последней — `/Bad-Reading-Club/` (или `/имя-репозитория/`); для custom domain или user pages — `/`. Workflow `.github/workflows/deploy.yml` собирает и публикует ветку `main`. Ссылки используют HashRouter, поэтому серверный fallback не требуется. После настройки и ручной отправки ветки workflow выполнится автоматически; организатору для работы с контентом GitHub не нужен.

## Проверка перед запуском

Откройте сайт из российских сетей без VPN и проверьте доступ как к Pages, так и к API и Storage Supabase. Проверьте анонимный просмотр и попытку записи без авторизации; затем войдите администратором, создайте книгу, измените рейтинг, опубликуйте встречу, загрузите фото и удалите тестовые данные. RLS и Storage должны отклонять запись анонимного пользователя и пользователя без роли. Эти проверки требуют собственного Supabase-проекта и не заменяются одной локальной сборкой.

Supabase Free может приостанавливать неактивные проекты; доступность из РФ, тарифы и бесплатные лимиты могут меняться. Убедитесь, что проект соответствует актуальным условиям сервиса и потреблению клуба.
